        Prepare
Source corpus
sources
        
Collect chosen episodes in a corpus and inspect its dates, domains and repeated text.
Starts with explicitly chosen source episodes.

        
import-text · inspect · select
Source preparation
      

      

        Prepare
Bounded packet
packet.md
        
Apply question and source filters. Measure the finished packet, then read the exact file before sharing.
Uses Source corpus.

        
preview · packet-stats · check-budget · build
Packet configuration
      

      

        Verify
Byte receipt
receipt.json
        
Bind a receipt to the reviewed packet bytes. Verify it again before using that file.
Uses Bounded packet.

        
receipt · verify-receipt
Integrity receipts
      

      

        Review
Structured report
report.json
        
Draft a local report or enter a response yourself. Validate answers against the configured corpus.
Uses Source corpus.

        
draft-report · validate-report
Report contract
      

      

        Review
Run snapshot
run.json
        
Freeze selected sources, the configuration and the validated report for an evidence map or comparison.
Uses Source corpus and Structured report.

        
pack-run · evidence-map · compare
Follow-up comparisons
      

      

        Review
Human review
review.json
        
Record explicit human decisions about each answer. Inspect gaps and export accepted excerpts.
Uses Run snapshot.

        
review-plan · review-gaps · export-accepted
Review decisions
      

      

        Follow up
Optional experiment
experiment.json
        
Use a run and its review to plan one accepted action. Record observations and your stop decision.
Uses Run snapshot and Human review.

        
plan-experiment · append-observation
Experiment records
